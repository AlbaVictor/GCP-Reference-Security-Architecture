# GCP Reference Security Architecture

An end-to-end Google Cloud reference architecture, designed in draw.io as part of my study of GCP network and security architecture. It covers the resource hierarchy, Shared VPC, hybrid and private connectivity, edge security (Cloud Armor, IAP), compute (Compute Engine, GKE, Cloud Run) and the logging and detection pipeline. Every entry and exit point to the environment is marked.
